Review this policy against the actual production hosting, analytics, embedded services, and consent tools before publication.

1. Overview

Cookies are small files or values stored by a browser. Similar technologies include local storage and session storage. The current project does not intentionally include advertising cookies or third-party analytics.

2. Essential storage

The PHP form handler may use a short-lived session cookie to apply basic same-session spam protection. This supports security and form operation and is not intended for advertising or cross-site tracking.

3. Analytics

No analytics tool is included in the current project. If analytics is added later, this policy and any consent mechanism must be updated before the tool is enabled.

4. Third-party content

The project uses local library files and does not intentionally embed third-party media. Production hosting, security, or email providers may process technical request data according to their configuration and terms.

5. Browser controls

Most browsers allow you to inspect, block, or remove cookies. Blocking essential session storage may affect form protection or other site functions.

6. Changes to this policy

This policy should be updated when cookies, analytics, embedded content, consent tooling, or hosting behaviour changes materially.
